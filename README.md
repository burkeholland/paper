# paper

A curated collection of AI-generated wallpapers in the Figma flat illustration style.

Browse and download at: https://burkeholland.github.io/paper

## Themes
- **Farm** — Nighttime pastoral scenes. Moonlit barns, starry pastures, country roads.
- **Suburbia** — The quiet beauty of American suburbs. Cul-de-sacs, snow days, block parties.
- **Bucolic** — Idyllic countryside scenes. Rolling hills, meadow paths, stone bridges.

28 wallpapers, all 4K (5504x3072) and free to use.
